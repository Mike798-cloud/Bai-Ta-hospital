# 白塔医院：零点交班（v4.0 完整发布版）

这是一个纯前端叙事解谜游戏，不需要服务器、数据库或构建工具。`index.html`、`css/`、`js/`、`assets/` 必须保持当前相对位置。

## 本版四个修改流程

1. **谜题与调查流程**：登录线索改为可交叉推导；床位、时间、监控、图纸、审计与现场恢复谜题均需主动比对，不再直接展示答案；系统按解锁、未读、已访问和已分析显示状态。
2. **剧情与逻辑**：统一 2013-09-16 夜班至 09-17 凌晨的跨日时间线；补足杜蓉救人、顾青禾留守、赵秉文篡改与切氧的责任链；结局同时检查证据完整度、危险操作和隐私选择。
3. **美术与场景**：医院日夜外景、护士站、档案室、医气阀门间、洗衣梯、药房、放射控制室、B7-0、报纸、监控序列与胸片均已更新为项目专用 WebP 资产。
4. **界面与体验**：修复封面开始按钮失效；精简顶部工具栏；补充更多菜单、三级提示、设置强度、减弱动态、环境音、自动存档和移动端布局。

## 上传 GitHub Pages

1. 先删除仓库中原有的站点文件，避免遗留旧版资源。
2. 解压发布包，把解压后看到的全部文件和文件夹直接上传到仓库根目录；不要再多套一层文件夹。
3. 仓库根目录应直接看到 `index.html`，并同时存在 `assets`、`css`、`js` 三个文件夹。
4. 在 GitHub 仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。
5. 发布后若仍看到旧页面，请等待 Pages 部署完成，再硬刷新浏览器（Windows：`Ctrl+F5`；macOS：`Command+Shift+R`）。

## Windows 一键校验与重新打包

双击 `build_release.bat`。脚本会检查 JavaScript 语法（电脑已安装 Node.js 时）、检查合并冲突标记，并在当前目录生成新的 `Bai-Ta-hospital-v4.zip`。

## 运行说明

- 推荐使用最新版 Chrome、Edge、Firefox 或 Safari。
- 进度保存在当前浏览器的本地存储中；清理站点数据会同时清除存档。
- 1 元支持为完全自愿，不付款也可完整游玩，页面不会验证真实支付。
- 游戏内医院、人物、项目和医疗事件均为虚构。
